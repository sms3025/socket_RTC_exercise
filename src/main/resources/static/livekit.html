[4단계] LiveKit 화상 연습 (SFU 방식)

2·3단계의 Mesh 는 모두가 모두에게 직접 영상을 올려서 인원이 늘면 부담이 컸다.
SFU 는 각자 LiveKit 서버 한 곳에만 영상을 올리고, 서버가 나머지에게 배분한다. → 인원이 많아져도(마피아 8~10명) 각자의 업로드 부담이 일정하다.

※ 먼저 LiveKit 서버를 띄워야 한다. (아래 STUDY.md 참고: livekit-server --dev 또는 Docker)
※ 카메라 접근은 localhost 또는 https 에서만 허용된다. 이 페이지는 https://localhost:8443/livekit.html 로 접속할 것.
